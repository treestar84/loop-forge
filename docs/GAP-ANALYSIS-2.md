# 갭 분석 2차 — 장기 · 오목 · 윙스팬 · 하스스톤 · 스플랜더 (v1.1 → v1.2)

> 방법: 게임별로 "이 게임을 실제로 온보딩하면 4계층의 어디가 부러지는가"를 가지별로
> 탐색(ToT)한 뒤, 게임을 관통하는 공통 실패 모드로 수렴시켰다. 1차(훌라·체스,
> GAP-ANALYSIS.md)에서 닫은 갭은 재검증만 하고 반복 기술하지 않는다.

---

## 게임별 가지 탐색

### 1. 장기 (완전정보 · 무작위성 없음 · 세팅 선택 · 한수쉼)

- ✅ 재검증: 완전정보(`perfectInformation`) C3 처리, 시드 다양성 검사, 종국 규칙
  (빅장/반복) remediation — 1차 처치로 커버됨.
- ⚠️ **[신규 G1] 결정 지점 기반 다양성의 함정**: 장기는 대국 시작 전 마·상 배치를
  각자 선택한다(4×4=16 조합). 이것을 결정 지점으로 모델링하면 자연스러운 오프닝
  다양성처럼 보이지만, **결정론적 봇은 항상 같은 배치를 고르므로 다양성이 0이 된다.**
  시드 다양성 검사(C1)는 random self-play로 검사하기 때문에 이 함정을 **통과해버린다**
  — random 봇은 배치를 랜덤하게 고르니까. 실제 웨이브(결정론적 후보 봇)에서만 전멸이
  드러난다. → 처치: 가이드에 "다양성은 봇 결정에 맡기지 말고 시드가 강제하라"(세팅을
  시드-강제하거나 오프닝북 병행) 명시 + 아래 공통 갭 X1(신호 붕괴 진단)이 런타임
  안전망이 된다.
- ✅ 한수쉼(패스 수)은 legal choice의 하나로 계약이 그대로 수용. 점수제 무승부 판정은
  composite score로 수용.

### 2. 오목 (완전정보 · 극단적 선공 우위)

- ⚠️ **[신규 X1 — 이 게임이 발견한 최중요 갭] 페어드 신호 붕괴**: 오목의 선공 우위는
  체스의 수 %p 수준이 아니라 (금수 규칙 없이는) 사실상 승패를 결정한다. 좌석 미러링은
  이 우위를 공정하게 **상쇄**하지만, 강한 봇끼리는 "흑 잡은 쪽이 이기는" 게임 2판이
  한 쌍이 되어 **모든 블록의 winFraction이 정확히 0.5로 수렴한다** — 편향은 상쇄됐지만
  **전략 차이의 신호도 함께 상쇄되어 통계가 전멸**한다. 부트스트랩 CI는 폭 0의 [0.5,
  0.5]가 되고 SPRT는 영원히 continue다. 체스 엔진 테스트가 **불균형 오프닝북**(한쪽이
  약간 유리한 국면을 미러로 배정)을 쓰는 진짜 이유가 이것이다. 현재 어떤 검사도 이를
  잡지 못한다. → 처치(구현): 캘리브레이션·웨이브 리포트에 **signalCollapseRate**(블록
  winFraction이 정확히 0.5인 비율) 지표 신설 + 임계 초과 시 "신호 붕괴 — 다양한/불균형
  오프닝 주입 필요" 경고. INTERPRETATION에 해석 규칙 추가.
- ✅ 금수 규칙의 구현 정확성은 C2(크래시)가 아니라 C7(parity fixture)의 몫 — 기존
  구조로 커버되나, 가이드에 "금수류 세부 규칙은 fixture로 검증하라" 명시.

### 3. 윙스팬 (170+ 카드 콘텐츠 · 게임 중 주사위/드로우 · 라운드제)

- ⚠️ **[신규 X2 — 콘텐츠 커버리지 맹점]**: 룰 엔진이 완벽해도 170여 종 새 카드 효과
  하나하나가 별도 구현이다. C2 랜덤 플레이아웃 200판은 **뽑힌 카드만** 실행한다 —
  절반의 카드가 미구현/오구현이어도 크래시만 없으면 만점으로 통과한다. 콘텐츠가 많은
  게임일수록 적합성 점수가 실제 완성도를 과대평가한다. → 처치(구현+계약): 어댑터가
  `contentInventory`(콘텐츠 id 목록)와 `exercisedContent(finalState)`(그 게임에서 실제
  발동/사용된 콘텐츠 id)를 선택 선언하면, C2가 플레이아웃 전체의 **콘텐츠 커버리지 %와
  미커버 목록**을 보고. 미선언 시 "콘텐츠 커버리지 미측정" note로 강등 경고.
- ⚠️ 가이드: **콘텐츠 증분 온보딩 전략** — 전체 카드를 한 번에 구현하지 말고, 기본
  카드 부분집합으로 먼저 G-Score 통과 → 루프 가동 → 콘텐츠를 배치로 확장하며
  커버리지를 늘리는 반복 경로를 표준으로 명시. (어댑터 1개=설정 1개 원칙과 결합:
  `wingspan-core`, `wingspan-full`.)
- ✅ 새모이통 주사위·드로우 = 상태 내 RNG 패턴(1차 B1)으로 커버. 사이 턴 발동
  분홍 파워(인터럽트)는 AEC의 `currentDecision`이 반응자를 반환하면 수용 — 가이드에
  인터럽트 모델링 명시.
- ⚠️ **[신규 G2] 1인/협력 모드 범위 명시**: 윙스팬 솔로(오토마) 같은 1인 모드는 승률
  기반 루프의 전제(경쟁 대국)와 안 맞는다. → 처치(구현): C0에서 `playerCount >= 2`를
  명시적 blocker로 강제하고 "v1은 경쟁 게임 전용, 솔로/협력은 로드맵" 문서화.

### 4. 하스스톤 (은닉+고밀도 RNG · 수천 장 콘텐츠 · 덱 구성 메타 · 동시 멀리건)

- ⚠️ **[신규 G3] 덱 = 설정, 좌석 결합 원칙**: 승률은 실력과 **매치업**(덱 상성)의
  곱이다. 덱을 좌석에 결합하면(좌석 0의 덱, 좌석 1의 덱) 좌석 미러링이 매치업도 함께
  미러링해 상성이 상쇄된다 — 이것이 올바른 기본값. 기본 권장은 **미러 매치**(양쪽 같은
  덱)로 실력만 측정, 상성 포트폴리오 평가는 어댑터 설정 여러 개(`hs-mirror-aggro`,
  `hs-cross-a-vs-b`)로. 덱 구성 자체를 전략 표면으로 여는 것은 로드맵(탐색 공간 폭발).
  → 가이드 성문화.
- ⚠️ **[신규 X3] 고분산 게임의 표본 설계**: RNG 밀도가 높을수록 노이즈 플로어가 넓어져
  기본 뱅크 크기(smoke 수십, prune/holdout 수백)로는 CI가 효과 크기를 못 가른다.
  현재는 사용자가 INTERPRETATION의 "noise floor" 개념으로 수동 판단해야 한다. →
  처치(구현): `recommendBlockCount(noiseFloorCI, targetEffect)` 헬퍼 — 캘리브레이션
  결과에서 "이 게임에서 승률 +N%p를 판정하려면 블록 몇 개가 필요한가"를 계산해
  캘리브레이션 리포트에 포함. 뱅크 크기 결정이 감이 아니라 절차가 된다.
- ✅ 동시 멀리건 = "순차 진행 + 상대 선택 은닉" 모델로 수용 — 단, 이 은닉이 C3 probe로
  검증 가능하도록 "멀리건 진행 중 상대의 선택을 변조해도 내 관찰 불변" 패턴을 가이드에
  명시. 발견(Discover)류 선택지 제시 랜덤 = 상태 RNG 패턴으로 커버. 트리거/오라 처리
  순서의 결정론은 C1이 잡는다.
- ⚠️ 콘텐츠 커버리지(X2)가 윙스팬보다 심각(수천 장) — 증분 온보딩 전략 필수. 팬 구현
  기반이면 C7 parity가 자기일관성으로 격하됨(1차에서 이미 성문화).

### 5. 스플랜더 (거의 공개 정보 · 덱 순서만 은닉 · 2~4인)

- ✅ 5개 중 가장 순한 대상: 콘텐츠 소량(카드 90장, 효과 동질), 은닉은 덱 순서+덱에서
  예약한 카드뿐(probe 표준형), 2~4인은 설정별 어댑터(1차 B4), 무한 루프 위험은
  maxDecisions가 방어. **실전 온보딩 1호 후보로 추천** — 온보딩 파이프라인 자체의
  실전 검증 비용이 가장 낮다.
- ⚠️ 동점 세부 규칙(카드 수 적은 쪽 승) 같은 종국 타이브레이커는 fixture 검증 대상
  (가이드 명시 수준).

## 수렴: 공통 실패 모드와 처치

| ID | 갭 | 발견 게임 | 심각도 | 처치 |
|---|---|---|---|---|
| **X1** | 페어드 신호 붕괴 — 미러링이 편향과 함께 신호까지 상쇄, 모든 블록 0.5 | 오목(극단), 장기·체스(잠재) | **치명** | v1.2 구현: signalCollapseRate 지표 + 경고, INTERPRETATION 규칙 |
| **X2** | 콘텐츠 커버리지 맹점 — 랜덤 플레이아웃이 미실행 콘텐츠를 통과시킴 | 윙스팬, 하스스톤 | **높음** | v1.2 구현: `contentInventory`/`exercisedContent` 계약 확장 + C2 커버리지 보고 |
| **X3** | 고분산 게임 표본 설계 부재 — 뱅크 크기가 감으로 결정됨 | 하스스톤(극단), 윙스팬 | 높음 | v1.2 구현: `recommendBlockCount` + 캘리브레이션 리포트 통합 |
| **G1** | 결정 지점 다양성 함정 — random 검사는 통과, 결정론 봇에서 전멸 | 장기 | 중간 | 가이드 (X1 지표가 런타임 안전망) |
| **G2** | 솔로/협력 모드 범위 미정의 | 윙스팬 | 중간 | v1.2 구현: C0 `playerCount>=2` blocker + 문서화 |
| **G3** | 덱/로드아웃 좌석 결합·미러 매치 원칙 부재 | 하스스톤 | 중간 | 가이드 |
| **G4** | 콘텐츠 증분 온보딩 전략 부재 | 윙스팬, 하스스톤 | 중간 | 가이드 |
| **G5** | 동시 결정의 은닉-순차 모델링 패턴 미성문화 | 하스스톤(멀리건) | 낮음 | 가이드 |
| **G6** | 세부 규칙(금수·타이브레이커)의 fixture 검증 원칙 | 오목, 스플랜더 | 낮음 | 가이드 |

**로드맵 이연**: 불균형 오프닝북 생성 도구(X1의 근본 해법), 덱 구성 탐색(하스스톤),
솔로/협력 게임 지원, GSPRT.

**전략적 권고**: 실전 온보딩 순서는 **스플랜더 → 오목 → 장기 → 윙스팬(core 부분집합)
→ 하스스톤**. 앞의 둘이 각각 "가장 싼 실전 검증"과 "신호 붕괴 대응의 실전 검증"을
제공한 뒤에 콘텐츠 무거운 게임으로 가는 것이 리스크 최소 경로다.
