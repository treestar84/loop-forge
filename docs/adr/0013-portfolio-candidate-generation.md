# ADR-0013 — 포트폴리오 후보 생성 (큰루프 설계 단계의 버킷 배분)

- 상태: 채택됨 (2026-07-29, GAP-ANALYSIS-11 D5/D5.5)
- 관련: ADR-0009(억지 반복 금지), ADR-0011(트리 prior), ADR-0012(앵커 래더)

## 맥락

큰루프 3단계(재설계)가 "그때 떠오른 아이디어 1개의 직렬 시도"였고 설계
품질·다양성을 담보하는 절차가 없었다(GAP-11 R4). 벤치마크 상대(Opus봇)에는
Opus급 집중 설계가 들어갔는데 루프포지 후보는 대부분 빠른 휴리스틱이었다는
비대칭 노력 문제를 FIX-BACKLOG가 자인했다. 사용자 지시: 후보 생성을 다관점
비중 분할로 구조화하라(단일 관점 편향 탈피).

## 결정

라운드당 후보 배치를 5개 버킷으로 나눠 생성하고, 비중은 수율로 재배분한다:

| 버킷 | 내용 | 생성 주체 | 초기 비중 |
|---|---|---|---|
| B1 활용 | 챔피언·near-miss 파라미터 변형(기계 생성, LLM 0) | 기계 | 25% |
| B2 상대 정보 | LossReport·프로브 불일치 겨냥 설계 | Sonnet | 25% |
| B3 심층 설계 | 설계 브리프 전체 기반 집중 설계 1~2개 | **Opus급(메인 루프)** | 15% |
| B4 신규 탐험 | 축 매트릭스 미시도 축, 행동 지문 원거리 우대 | Sonnet | 25% |
| B5 모방·이식 | 앵커 클로닝·타 게임 성공 패턴 이식 | Sonnet | 10% |

- 비중 재배분: 버킷 수율(채택률 0.5 + challenge 승률 Δ 0.5 가중)에 비례,
  **하한 5%**(탐험 소멸 방지), 전 버킷 수율 0이면 현 비중 유지.
- 배치 크기는 고정 상수가 아니라 처리량 실측 파생(프로브 필터 통과율 ×
  후보당 웨이브 비용) — P6(고정 임계의 부당함) 교훈의 일관 적용.
- 설계 브리프(`artifacts/design-brief.ts`)가 B2~B5의 표준 입력이며, 홀드아웃
  앵커(L3) 정보는 브리프에 구조적으로 배제된다(ADR-0012의 가드와 이중 방어).
- ADR-0009와의 관계: 금지되는 것은 "같은 축의 수동 재시도"다. B1의 기계적
  스윕은 수율이 낮으면 비중이 자동 축소되므로 "사람이 억지로 같은 손잡이를
  돌리는" 구조와 다르다 — 적용 단위를 이렇게 명확화한다.

## 대안

- **매 라운드 전량 Opus 설계**: 품질은 높지만 비용 선형 폭발 + 관점 단일화.
  모델 라우팅(B3만 Opus급, B1은 LLM 0)이 같은 품질 상한을 유지하며 비용을
  통제한다.
- **사용자 제안 원안(라운드당 100개 고정, 고정 % 배분)**: 현 예산(단일 맥북,
  무거운 연산 동시 1개)에서 100후보×다단 게이트는 불가하고 고정 상수는 P6
  교훈 위반 — "많이 생성, 프로브로 싸게 선별, 소수만 웨이브" 구조와 수율 기반
  재배분으로 제안의 본질(다관점·대량 탐색)을 보존하며 조정했다(GAP-11 §4).
- **완전 자동 스케줄러(밴딧 알고리즘 정식 구현)**: 수율 데이터가 3라운드
  쌓이기 전엔 과설계 — v1은 결정론적 비례 재배분 + 하한으로 시작한다.

## 결과

- 실증 1회전(오목·도미니언)은 GAP-11 §5.5에 기록 예정. 리스크: 버킷 관리
  오버헤드가 배보다 배꼽이 되는 것 — v1은 마크다운+JSON 기록 수준으로 제한.
