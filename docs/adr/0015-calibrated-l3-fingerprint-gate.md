# ADR-0015: L3 홀드아웃 지문 게이트의 게임 보정 (calibrated fingerprint gate)

- 상태: 채택 (2026-08-04)
- 관련: ADR-0012(앵커 래더·홀드아웃), FIX-BACKLOG E10, GAP-11-ROUNDS.md
  "윙스팬 GAP-11 편입"

## 맥락

L3 홀드아웃 앵커 등록 게이트 2(행동 지문 거리)는 지금까지 고정 임계였다:
같은 프로브 국면에서 L3와 L2의 선택 일치율이 **70% 미만**이어야 등록된다.
오목(69.2%)·도미니언·하스스톤·스플랜더(49.8%)에서는 이 임계가 잘
작동했지만, 윙스팬에서 실측 반례가 나왔다: L2 소스를 전혀 읽지 않은 독립
에이전트가 명시적으로 다른 철학(먹이 경제+알 스퍼트)으로 설계한 봇이
**일치율 84.0%(336/400)** 로 게이트에서 떨어졌다.

원인은 설계 오염이 아니라 **게임의 분기 폭**이다: 윙스팬은 턴당 행동이
4종뿐이라, 서로 다른 철학의 두 봇도 대부분의 결정 지점에서 같은 선택으로
자연 수렴한다. 고정 임계 70%는 "지문의 판별력이 게임 불변"이라는 암묵
가정을 깔고 있었고, 그 가정이 좁은 선택지 게임에서 깨진 것이다.

## 결정

게이트 2를 **게임 보정형 2단 판정**으로 개정한다:

1. **절대 임계 fast-pass (기존 유지)**: 일치율 < 70%면 그대로 통과.
   기존 4게임의 등록 결정은 전부 이 경로로 재현되므로 소급 영향이 없다.
2. **보정 판정 (신설, fast-pass 실패 시)**: 같은 프로브 프로토콜로
   **독립성이 자명한 두 봇**(plain heuristic vs L2 — 서로 무관하게 만들어진
   봇 쌍)의 일치율을 재서 그 게임의 **자연 일치율 바닥(floor)** 으로 삼고,
   정규화 초과 일치율을 계산한다:

   ```
   excess = (agreement(L3,L2) − floor) / (1 − floor)
   ```

   **excess < 0.5면 통과** — "L3는 '독립 봇 쌍'보다 '동일 봇'에 더 가깝지
   않다"는 뜻이다. floor ≥ agreement면 자명 통과(독립 쌍보다도 멀다).
   0.5는 중점 기준이다: 독립(floor)과 동일(1.0) 사이의 중간보다 독립 쪽에
   있어야 한다 — 임의 상수를 새로 발명하는 대신 "무엇의 중간인가"가
   자명한 값을 쓴다.

게이트의 목적은 변하지 않는다: **L3가 사실상 L2와 같은 상대가 되어
홀드아웃 독립성이 무너지는 것을 막는 것.** 바뀐 것은 "같음"의 기준을
게임의 자연 일치율로 상대화한 것뿐이다.

## 대안과 기각 사유

- **임계를 84%보다 높게 올리기**: 윙스팬을 통과시키기 위한 게이트 쇼핑 —
  근거 없는 상수 교체라 기각. 보정형은 윙스팬이 여전히 떨어질 수 있다
  (floor가 낮게 나오면 excess ≥ 0.5). 그 경우 결론은 "더 극단적인 L3
  설계가 필요하다"이지 "임계를 또 완화한다"가 아니다.
- **판별 결정만 계수(강제수 제외)**: 합법수가 적거나 참조 봇들이 만장일치인
  지점을 제외하고 일치율을 재는 방식 — 원리적으로 좋지만 "강제수" 판정
  자체에 추가 장치(참조 봇 패널)가 필요해 이번 범위에서는 보정형보다
  구현 비용이 높다. 보정형이 실패 사례를 더 내면 재검토.
- **상호 대전 비이행성 검사**: GAP-11 §6이 언급한 보조 신호 — 지문과
  상호 보완적이지만 단독으로는 "다른 스타일"과 "같은 실력의 클론"을
  구분하지 못한다. 필요 시 추가 신호로 도입.

## 결과

- 소급 영향 없음(기존 등록은 전부 fast-pass 경로로 동일 판정).
- 윙스팬 L3 재판정은 floor 실측에 달렸다 — 통과·불통과 어느 쪽이든
  근거가 게임 자체의 수치로 남는다. 불통과면 지정된 대체 철학으로 1회
  재설계를 시도하고, 그것도 떨어지면 "현 프로토콜로 윙스팬 L3 구성
  불가"로 정직하게 기록한다.
